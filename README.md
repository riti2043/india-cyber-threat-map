# AURA: Citizen Accessibility Portal (React.js + Vite Version)

A fully functional port of the AURA Citizen Accessibility Suite rebuilt in **React.js** and styled with a **Neon Space Cyberpunk** design system (glassmorphism cards, glowing active state colors, space-grid backdrops, and glowing indicator lights).

---

## 🚀 How to Run Locally

Since this is a standard React.js Vite application, follow these steps to install and start the dev server:

1. Open your terminal of choice (CMD, PowerShell, or Git Bash).
2. Navigate into the React project directory:
   ```bash
   cd "c:\Users\pavit\Downloads\CPU_SchedulingAlgorithms-main (2)\aura-suite-react"
   ```
3. Install the dependencies declared in `package.json`:
   ```bash
   npm install
   ```
4. Start the local Vite development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to the local URL (usually `http://localhost:3000` or the port shown in your terminal).

## 🌌 Key Highlights & AI Features

1.  **Continuous Speech Navigation**: Activate using the **Voice Assistant Hub** on the Dashboard. Dictate commands like *"scroll down"*, *"open reader"*, *"open map"*, or *"go home"* to control page position and routing.
2.  **Multilingual OCR Scanner**: Drag and drop documents inside the Smart Reader to invoke client-side WebAssembly **Tesseract OCR** text parsing.
3.  **Spoken Form Filler & Verification**: Select English, Hindi, or Kannada, speak values to fill the welfare form fields, verify input via robotic read-back, and compile to a clean **welfare scheme PDF** (`html2pdf.js`).
4.  **Empathy Simulators**: Toggle global color filters to simulate red-green/blue-yellow blindness, scramble letters to simulate reading fatigue, or feed your camera stream to test sign language numbers recognition.
5.  **Beep Spatial Cricket**: Play cricket using spatial sound pitch indicators. Tap swing or speak *"swing"* at the highest tone pitch to score runs.
